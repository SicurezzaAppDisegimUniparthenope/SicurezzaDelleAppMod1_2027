\question[4]
Cos'è la \textbf{memory corruption}? Qual è la radice comune delle sue tecniche e quali due aree di memoria può colpire?
\begin{solution}
È la modifica di locazioni di memoria per alterare il comportamento atteso del programma. È tra le classi di vulnerabilità più antiche.
Radice comune: il \textbf{buffer overflow} (scrivere oltre i limiti di un buffer). Può colpire lo \textbf{stack} o l'\textbf{heap}.
\end{solution}
